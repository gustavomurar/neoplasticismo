# Neo Plasticismo — reprodução HTML

Esta pasta reproduz visualmente as 3 páginas presentes no PDF fornecido, usando as próprias páginas renderizadas em alta fidelidade para preservar exatamente:
- posições;
- formas;
- cores;
- textos;
- espaçamentos;
- proporções;
- cabeçalho e rodapé.

Arquivos:
- index.html — estrutura e navegação.
- styles.css — estilo e hotspots.
- script.js — navegação e área "Crie sua obra".
- assets/page1.png, page2.png, page3.png — renderizações exatas das páginas do PDF.
- assets/* — seis imagens de obras extraídas do PDF.
- sources.json — registros/fontes oficiais consultadas para as obras.

Observação importante:
O PDF enviado contém 3 páginas. O item "CRIE SUA OBRA" aparece no menu, mas não existe como uma quarta página no PDF. Por isso, a reprodução mantém as 3 páginas exatamente como fornecidas e adiciona uma pequena área interativa somente quando esse item é acionado.

As imagens das obras que aparecem visualmente nas páginas são as imagens já incorporadas no material fornecido. Cada área de obra na página "OBRAS" possui um link invisível para o registro oficial correspondente, para permitir a conferência da obra e da coleção.
